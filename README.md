# wytina.com

Personal website of Yitian Wang (Tina). A single static page: `index.html`, with photos in `images/` and the English typeface Hanken Grotesk (SIL Open Font License, see `fonts/OFL.txt`) in `fonts/`.

All text lives in the `CONTENT` block near the top of the script in `index.html`, as [Chinese, English] pairs.
